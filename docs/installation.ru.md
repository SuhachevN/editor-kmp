# Установка Comixon Editor с GitHub

[English version](installation.en.md)

## Скачать сборку

1. Войди в GitHub под аккаунтом с доступом к [SuhachevN/editor-kmp](https://github.com/SuhachevN/editor-kmp). Репозиторий приватный.
2. Открой **Actions → Build and test** или перейди на [страницу сборок](https://github.com/SuhachevN/editor-kmp/actions/workflows/ci.yml).
3. Выбери последнюю успешную сборку ветки **main** с зелёной галочкой. Если новая сборка ещё выполняется, можно взять предыдущую успешную.
4. Пролистай до блока **Artifacts**, нажми на нужное название из таблицы и распакуй скачанный ZIP.

| Платформа | Артефакт | Что открывать |
| --- | --- | --- |
| Android 8.0+ | `android-demo` | `androidApp-debug.apk` |
| Windows x64 | `windows-demo` | `ComixonEditor.exe` |
| macOS, Apple Silicon | `macos-demo-macos-15` | Файл `.dmg` |
| macOS, Intel | `macos-demo-macos-15-intel` | Файл `.dmg` |
| iOS 15+ | `ios-unsigned` | `comixon-editor-unsigned.ipa`, после подписи |
| Linux | Исходный код | См. раздел [Linux](#linux) |

Названия артефактов заданы в CI. Например, `macos-15` обозначает среду сборки, а не отдельную редакцию приложения. Готовые файлы находятся в запусках Actions, а не в разделе Releases.

Для скачивания артефактов нужно войти в GitHub и иметь доступ на чтение репозитория. Срок хранения ограничен; по умолчанию GitHub хранит их 90 дней. См. [инструкцию GitHub](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts).

## Android

1. Скачай и распакуй `android-demo` на телефоне либо перенеси уже распакованный APK с компьютера.
2. Открой `androidApp-debug.apk` через файловый менеджер телефона.
3. Если Android попросит, разреши этому браузеру или файловому менеджеру установку приложения и подтверди установку.
4. Открой **Comixon Editor**.

Это отладочная сборка для тестирования. Для установки не нужны Android Studio, Java или аккаунт Comixon.

## Windows

1. Скачай `windows-demo` на компьютер с Windows x64.
2. Нажми на ZIP правой кнопкой и выбери **Извлечь всё**.
3. Открой распакованную папку и запусти `ComixonEditor.exe`.

Сохрани всю структуру папки, включая `app` и `runtime`. Запуск прямо из ZIP или перенос одного EXE не подойдут. Java уже входит в комплект приложения.

## macOS

1. Открой **меню Apple → Об этом Mac**. Для чипа Apple серии M нужен `macos-demo-macos-15`, для процессора Intel — `macos-demo-macos-15-intel`.
2. Скачай и распакуй подходящий артефакт, затем открой DMG.
3. Скопируй **ComixonEditor.app** в **Программы / Applications**.
4. Запусти приложение из этой папки.

Тестовые сборки не подписаны сертификатом Developer ID и не нотарифицированы Apple. Если macOS блокирует запуск из-за непроверенного разработчика и ты доверяешь сборке из этого репозитория, открой **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**, если этот пункт доступен. См. [инструкцию Apple по первому запуску](https://support.apple.com/en-us/102445).

Если система сообщает, что приложение повреждено, или не предлагает разрешить запуск, запусти его из исходников: установи JDK 17 и инструменты командной строки Xcode, скачай код по инструкции из раздела Linux и выполни `./gradlew :sample:run` в папке проекта. Инструменты Xcode предоставляют `swiftc` для помощника диктовки. В готовом DMG Java и помощник уже включены.

## iOS

IPA — неподписанная сборка для ARM64-устройств с iOS 15+. Скачивание или нажатие на файл в iPhone не устанавливает приложение: сначала нужна подпись для устройства.

### Установка через Windows и Sideloadly

Понадобятся iPhone, USB-кабель, твой Apple ID и компьютер с Windows.

1. Скачай и распакуй `ios-unsigned`. Внутри будет `comixon-editor-unsigned.ipa`.
2. Установи [Sideloadly с официального сайта](https://sideloadly.io/). Для Windows ему нужны версии **iTunes и iCloud с сайта Apple**, ссылки на которые приведены на странице загрузки, а не версии из Microsoft Store.
3. Подключи iPhone по USB, разблокируй его и подтверди **«Доверять этому компьютеру»**.
4. Открой Sideloadly, выбери iPhone и перетащи IPA в окно программы.
5. Укажи свой Apple ID и нажми **Start**. Вход в аккаунт пройди самостоятельно в Sideloadly.
6. На iOS 16+ при необходимости включи **Настройки → Конфиденциальность и безопасность → Режим разработчика**, выполнив перезагрузку и подтверждения на телефоне.
7. Если появится сообщение о ненадёжном разработчике, открой **Настройки → Основные → VPN и управление устройством**, выбери Apple ID, использованный для подписи, и подтверди доверие его профилю разработчика.
8. Открой **Comixon Editor**.

С бесплатным Apple ID подпись действует семь дней. Затем подпиши приложение повторно с тем же Apple ID и идентификатором приложения либо настрой автоматическое обновление подписи в Sideloadly. Перед переустановкой или обновлением экспортируй проекты. Продление, режим разработчика и обнаружение телефона описаны в [официальном FAQ Sideloadly](https://sideloadly.io/faq).

Пароль Apple ID, коды подтверждения и сертификаты используются в твоей среде подписи. Репозиторию и GitHub Actions они не нужны.

### Запуск через Xcode на Mac

1. Установи Xcode, JDK 17 и [XcodeGen](https://github.com/yonaskolb/XcodeGen#installing).
2. Скачай исходники через **Code → Download ZIP** и распакуй архив.
3. В Терминале открой папку распакованного проекта и выполни:

   ```sh
   chmod +x gradlew
   xcodegen generate --spec iosApp/project.yml
   open iosApp/ComixonEditor.xcodeproj
   ```

4. Выбери схему **ComixonEditor**. На Mac с Apple Silicon выбери симулятор iPhone и нажми **Run**.
5. Для запуска на подключённом iPhone открой **ComixonEditorApp → Signing & Capabilities**, выбери свою команду разработчика, укажи телефон как устройство запуска и нажми **Run**.

Kotlin-фреймворк собирается скриптом Xcode. CocoaPods не используется. Симулятор для Intel не настроен; целевая архитектура физического устройства — ARM64.

## Linux

На Linux редактор пока запускается из исходников: готовый установщик в CI не публикуется. Среда проверки CI — Ubuntu x86_64.

1. Установи **JDK 17** через менеджер пакетов своего дистрибутива. Проверь, что `java -version` показывает версию 17.
2. Войди в GitHub, открой репозиторий и выбери **Code → Download ZIP**.
3. Распакуй архив. Открой терминал в папке проекта, где находятся `gradlew` и `settings.gradle.kts`.
4. Выполни:

   ```sh
   chmod +x gradlew
   ./gradlew :sample:run
   ```

При первом запуске Gradle скачивает зависимости, поэтому нужен интернет. Запускай приложение в графической сессии рабочего стола. Для кнопки микрофона в редакторе пока нет Linux-адаптера; ввод с клавиатуры доступен.

## Первая проверка и обновление

Нажми **Choose photos / Выбрать фото**, чтобы начать со своих изображений, либо **Open demo / Открыть демо**, чтобы посмотреть пример. Добавь бабл, измени текст, проверь undo/redo, сохрани JSON-проект и экспортируй PNG.

Локальное редактирование не требует аккаунта Comixon. Без токена сессии Comixon кнопка **Start generation** показывает уведомление об авторизации и не отправляет запросы. AI-фильтры работают по правилам доступа текущего сервера. Диктовка зависит от службы распознавания ОС; могут понадобиться разрешение микрофона и интернет. Подробности — в [чек-листе проверок](testing.md).

Для обновления экспортируй проекты и установи новую сборку тем же способом. На Windows сохраняй всю папку приложения вместе; на iOS при продлении используй тот же Apple ID и идентификатор приложения.

Если срок хранения артефакта истёк, участник репозитория с правом записи может открыть **Actions → Build and test → Run workflow**, выбрать **main** и запустить новую сборку. Дождись её завершения, затем скачай артефакты. Сборка iOS может занимать заметно больше времени, чем Android.
